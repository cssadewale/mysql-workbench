# Changelog

## [3.0.0] - 2026-05-27

### Added
- Enterprise governance center with privacy, auditability, business continuity, and cost-control guidance.
- Local audit log for queries, imports, exports, restores, errors, and sample dataset loads.
- Performance dashboard with execution time, row count, and query preview.
- Built-in SQL lint report for common risky or inefficient exploration patterns.
- Visual table designer.
- SQLite backup restore workflow.
- Query result CSV export.
- Saved query library using browser LocalStorage.
- Built-in feature documentation panel.
- Dark/light theme toggle.
- Backup policy modal.
- GitHub-ready project structure with security, privacy, architecture, and deployment docs.

### Enhanced
- Preserved original query editor, schema explorer, CSV import, SQLite export, sample datasets, charting, ERD, console, SQL snippets, and MySQL Workbench-like UI.
- Removed dependency on paid services and maintained no-AI-API architecture.
- Improved mobile/tablet responsiveness and local persistence.
