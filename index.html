Backup Policy
  1. Export a SQLite backup at the end of every major work session.
  2. Name backups with date, project, and version, for example school_analytics_2026-05-27_v1.sqlite.
  3. Store at least two copies: device storage plus GitHub release, Google Drive, OneDrive, or external drive.
  4. Never store sensitive student, customer, or payroll data in a public repository.
